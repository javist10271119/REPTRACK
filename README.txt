REPTRACK — Android-installable web app

WHAT'S INCLUDED
- Responsive workout tracker
- Custom routines and exercises
- Daily exercise check-off and completion history
- Weekly activity calendar
- Local browser storage
- JSON backup export/import
- Offline app shell (service worker)

IMPORTANT
This ZIP is the app source package, not an APK. For Android's "Install app" option,
the files must be hosted at an HTTPS address. A static host such as GitHub Pages
or Netlify can serve this folder. After deployment:
1. Open the HTTPS site in Chrome on your Android phone.
2. Open Chrome's three-dot menu.
3. Tap "Install app" or "Add to Home screen".
4. Confirm the installation.

DATA
Workout data is stored locally in the browser on that device. It does not sync
between devices. Use History > Export backup to save a JSON backup periodically.
